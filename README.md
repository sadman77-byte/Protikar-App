# Protikar

**Live Location Tracking & Audio Assistance for the Visually Impaired**

Protikar is a lightweight, browser-based web application designed to help visually impaired users (and anyone else) share and understand their real-time location through audio feedback, nearby landmarks, and multi-language support.

---

## ✨ Features

- **Live Location Tracking**  
  Real-time GPS tracking with location history and accuracy indicators.

- **Audio Assistant**  
  Automatically describes the current location and nearby places. Supports auto-announce while scrolling.

- **Nearby Landmarks**  
  Shows nearby institutions (hospitals, banks, bus stops, etc.) with distance and direction (e.g., “430 meters east”).

- **Multi-language Support**  
  Currently supports:
  - বাংলা (Bangla)
  - English
  - हिन्दी (Hindi)
  - 中文 (Chinese)

- **Find a Friend**  
  Search by username or mobile number to view a friend’s shared location.

- **Compass & Direction Feedback**  
  Provides directional information relative to nearby places.

- **Manual Location Search**  
  Fallback option when GPS is unavailable (search by address or place name).

- **Privacy Focused**  
  Claims row-level security — only the user can access their own location data.

---

## 🎯 Target Users

- Visually impaired individuals who need audio-based location awareness
- Friends and family who want to track loved ones in real time
- Anyone needing a simple, install-free location sharing tool

---

## 🛠️ Tech Stack

- Built with **[Bolt](https://bolt.new)** (AI-powered web app builder)
- Browser Geolocation API
- Reverse Geocoding
- Text-to-Speech (TTS) for audio feedback
- Responsive web interface (works on mobile & desktop)

---

## 🚀 How to Use

1. Open the app in any modern browser.
2. Sign up / Sign in.
3. Allow location permission when prompted.
4. Tap **Start Live Tracking**.
5. Use **Audio Assistant** or enable **Auto-announce** for spoken feedback.
6. Scroll to hear interface guidance and nearby landmarks automatically.
7. Use **Find a Friend** to search for others by username or number.

## ⚠️ Current Limitations

- GPS accuracy drops significantly indoors.
- Voice numbers may occasionally speak in the wrong language (TTS configuration).
- Requires active internet connection and location permission.
- Still a prototype — not production-hardened for large-scale use.
- Background tracking reliability depends on the browser and device.
